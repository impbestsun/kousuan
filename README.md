# 口算练习（网页版）

**在线使用：** https://impbestsun.github.io/kousuan/ （口算训练直达：https://impbestsun.github.io/kousuan/#practice ）

老师给的「口算大师全能标准版」是 Windows 程序，只能在电脑上装了用。这里把它做成了网页：手机、平板、电脑的浏览器都能打开，不用安装。

整个网站只有一个文件：`index.html`。在电脑上双击就能直接用；放到任何网站空间里，就是在线版。

## 功能

- **出题打印**：71 种内置题型，设置和原软件完全一致（从「5以内加法」到「三位整十数乘以两位整十数」）。也可以自己设置算式：2～4 个数、每个数的范围、整十数/整百数、运算符号、得数范围、有无进位/借位/余数。
  - 题目形式：求得数、填空题（8 +（　）= 15）、两种混合
  - 答案：不显示、写在题目上、另附答案页
  - 每页题数、每行几题、页数可调，A4 直接打印或存成 PDF；也能复制到 Word/WPS
- **口算训练**：计分、计时、限时三种模式；交卷自动判分，按错题数评等级（婴儿 → 状元，规则和原软件一样）；可以只练错题；平板和手机上有屏幕数字键盘；快捷键 S 开始、F 交卷、C 出题。
- 设置和练习记录只保存在当前设备的浏览器里，不上传任何数据。

## 部署到网上（任选一种）

这是一个纯静态网页，不需要服务器程序，也不需要数据库，上传 `index.html` 就行。

1. **GitHub Pages（免费）**：新建一个仓库，上传 `index.html`，在仓库的 Settings → Pages 里选择 main 分支。几分钟后网址是 `https://你的用户名.github.io/仓库名/`。
2. **Netlify 或 Cloudflare Pages（免费）**：注册后，在网页上把 `kousuan` 文件夹拖进去上传即可。
3. **Vercel（免费）**：在 `kousuan` 文件夹里运行 `npx vercel deploy --prod`。
4. **国内访问更快**：腾讯云 EdgeOne Pages、阿里云 OSS 静态网站托管，或者自己的服务器（Nginx 等），把 `index.html` 放进网站根目录。

## 使用小提示

- 打印时纸张选 A4；想留电子版，在打印窗口里选「存储为 PDF」。
- 在微信里打开不能打印：点右上角「…」，选「在浏览器打开」。
- 网址后面加上 `#practice`（例如 `https://…/#practice`），打开就直接是口算训练页，适合加到孩子平板的主屏幕上。
